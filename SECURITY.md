# Security Policy

## Supported Versions

Only the latest released version of TaskMinder receives security updates. Older versions are not actively maintained and will not receive patches for security vulnerabilities.

## Reporting a Vulnerability

We take security issues seriously and aim to address them as quickly as possible. If you discover a vulnerability, please report it responsibly using **Email:** [info@taskminder.de](mailto:info@taskminder.de). 

Please include as much detail as possible in your report: steps to reproduce, potential impact, and any suggested mitigations are all helpful.

## Our Commitment

We are committed to resolving confirmed security vulnerabilities as soon as possible. Upon receiving a valid report, we will:

1. Acknowledge receipt of your report promptly.
2. Investigate and assess the impact of the vulnerability.
3. Release a fix in the shortest time possible.
4. Credit the reporter (unless you prefer to remain anonymous).

Thank you for helping keep TaskMinder secure!
